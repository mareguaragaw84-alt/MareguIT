# MareguIT
• የሶፍትዌር እና ድረ-ገጽ አልሚ (Software &amp; Web Developer): መተግበሪያዎችን (Apps)፣ ሶፍትዌሮችን እና ድረ-ገጾችን በኮዲንግ (Coding) መገንባት። • የኔትወርክ መሐንዲስ (Network Engineer): የድርጅቶችን የኮምፒውተር ግንኙነት እና የኢንተርኔት መሠረተ-ልማት መዘርጋትና ማስተዳደር። • የሳይበር ደህንነት ባለሙያ (Cybersecurity Specialist): ሲስተሞች እና መረጃዎች ከሃከሮች (Hackers) እና ከሳይበር ጥቃት የተጠበቁ መሆናቸውን ማረጋገጥ።
